# Rast Creator Tools — Privacy Policy

> Published at **https://rastcreative.com/en/tools/creator-tools-mcp-privacy/** (site repo `src/pages/en/tools/`). Keep both in sync. Endpoint: `https://rast-creator-tools-mcp.studio-c25.workers.dev/v1/mcp`.

**Rast Creator Tools** (the "app") is a free remote MCP server by Rast Creative Studio (rastcreative.com) that answers video-production questions inside AI assistants such as Gemini. Last updated: 1 November 2026.

## Short version
The app collects no personal data, needs no account and stores nothing. Each request is calculated and answered, then forgotten.

## What the app receives
When you ask an assistant a question that uses the app, the assistant sends the app only the values the tool needs, for example a platform name ("reels"), frame size, a text box position, a video duration and bitrate, or the text of a subtitle file you chose to check. The app does not receive your name, email, Google account, contacts, location or conversation history.

## What the app does with it
- The values are used only to calculate the answer for that request (safe-zone margins, overlap check, file size, subtitle issues, export settings).
- Nothing is written to a database, file, cache or log by the app. There are no cookies, analytics, advertising or tracking.
- Subtitle text is processed in memory for the single response and discarded.
- No data is sold, shared or used to train models.

## Hosting
The app runs on Cloudflare Workers. Like any web host, Cloudflare handles network data such as IP addresses to deliver requests and protect against abuse, under Cloudflare's own privacy policy (https://www.cloudflare.com/privacypolicy/). Application logging is turned off.

## Your choices and deletion
Because the app stores nothing, there is no data to view, export or delete. You can disconnect the app in your assistant's settings at any time (in Gemini: Settings → Connected apps). Questions: studio@rastcreative.com.

## Children
The app is a general-audience production tool and is not directed at children.

## Changes
If the app ever starts handling data differently, this page will be updated before the change and the date above will change.
